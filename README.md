## Bbsmc Monorepo

Welcome to the Bbsmc Monorepo, the primary codebase for the Bbsmc web interface and app. It contains ![Lines of Code](https://img.shields.io/endpoint?url=https://loctopus.creeperkatze.dev/github/Bbsmc/code/badge%3Fformat%3Dhuman&logoColor=white&color=black&label=) lines of code and has ![Contributors](https://img.shields.io/github/contributors/Bbsmc/code?color=black&label=) contributors!

If you're not a developer and you've stumbled upon this repository, you can access the web interface on the [Bbsmc website](https://bbsmc.org.cn) and download the latest release of the app [here](https://bbsmc.org.cn/app).

## Development

This repository contains two primary packages. For detailed development information, please refer to their respective guides:

- [Website frontend](https://docs.bbsmc.org.cn/contributing/knossos/)
- [Desktop app](https://docs.bbsmc.org.cn/contributing/theseus/)

## Contributing

We welcome contributions! Before submitting any contributions, please read our [contributing guidelines](https://docs.bbsmc.org.cn/contributing/getting-started/).

If you plan to fork this repository for your own purposes, please review our [copying guidelines](COPYING.md).

## Security

If you discover a security vulnerability within our codebase, please follow our [responsible disclosure guidelines](https://bbsmc.org.cn/legal/security).

## Support

If you need help with the Bbsmc web interface or app, please visit our [support page](https://support.bbsmc.org.cn). For general inquiries, you can also join our [Discord server](https://discord.bbsmc.org.cn).
